# Wireframe (v1)

Low-fidelity wireframe for the Group 5 data story website (COS30045).

## Files
- `index.html` – page structure (one section per research question)
- `css/style.css` – wireframe styles
- `js/main.js` – toolbar button (design notes on/off)

## Run locally
Open this folder in VS Code, right-click `index.html` and choose **Open with Live Server**.

This is a design draft only, not the final website.
